Employee Data Analysis – Week 1 Assessment

1. Project Overview

This project focuses on employee data analysis using Python and its popular data science libraries.

The main goal is to understand employee information, analyze salary details, calculate department-wise statistics, and visualize employee distribution across different cities.

This project demonstrates Python programming, data handling, data analysis, and data visualization skills.

2. Project Objectives

- Practice Python programming concepts.
- Understand Object-Oriented Programming (OOP).
- Work with NumPy arrays.
- Read and process CSV files using Pandas.
- Perform data cleaning and analysis.
- Calculate salary statistics.
- Create charts using Matplotlib.
- Generate meaningful insights from employee data.
